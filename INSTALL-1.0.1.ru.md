# Установка Order calculator 1.0.1

## Что входит

- Готовый ZIP: dist/1.0.1/UsrOrderCalculator-1.0.1.zip.
- C# схема UsrOrderCalculatorService: умножает quantity на unitPrice, проверяет диапазоны.
- Веб-карточка: Quantity, Unit price, Total, Calculate и сообщение об ошибке/успехе.
- Исходная регистрация приложения, объекта и навигации из экспорта сохранена.
- Имя, UId пакета и существующих схем сохранены: архив обновляет Order calculator,
  а не создаёт вторую копию приложения. Пакет Test app не входит и не изменяется.
- Значения калькулятора временные: они сбрасываются при открытии карточки и не сохраняются в MSSQL.
  Name и остальные прежние данные работают как в исходном приложении.

## Перед установкой

1. Закрыть пустой редактор UsrOrderCalculatorService, не сохраняя пустую схему поверх нового кода.
2. Сохранить резервную копию creatio_app; команда ниже создаёт COPY_ONLY backup с CHECKSUM,
   не перезаписывая существующий файл. Она не останавливает приложение.
3. Исходный экспорт приложения сохранён в dist/1.0.1/original-export.zip.
   Это резервная копия исходного пакета, а не всей базы или Design PVC.

В терминале запустить подготовленный scripts/backup-before-install.sh.
Команда использует существующий MSSQL_SA_PASSWORD внутри SQL-контейнера; пароль не печатается.
Backup сохраняется сначала в /var/opt/mssql/backup контейнера, затем копируется в host-папку
backups/order-calculator-* основного инфраструктурного проекта. После запуска проверить вывод.

## Установка

1. Application Hub → New application → Install from file.
2. Выбрать dist/1.0.1/UsrOrderCalculator-1.0.1.zip.
3. Прочитать результат проверки зависимостей. Архив требует ту же среду, что и исходное
   приложение: Studio 8.3.3 и зависимости исходного пакета. Не обходить сообщения о несовместимости.
4. Установить архив, дождаться завершения компиляции. Во время установки не запускать другую компиляцию.
5. При ошибке сохранить installation log; не повторять установку до разбора причины.

## Проверка

- В браузере с действующей сессией:
  https://creatio.creatio.test/rest/UsrOrderCalculatorService/Calculate?quantity=3&unitPrice=1250.50
  Ожидается CalculateResult.Success=true и Total=3751.5.
- Application Hub → Order calculator → Run app → New.
- Quantity=3, Unit price=1250.50, Calculate → Total=3751.50 (формат числа зависит от UI/локали).
- Quantity=0 → сообщение ошибки, HTTP-вызов не отправляется.
- Раздел навигации использует исходную привязку My applications. Порядок после Test app при
  необходимости меняется в настройках навигации; точная позиция не принудительно переписывается архивом.

## Публикация на Worker

После успешной проверки Design: Control Plane → publish order-calculator-v1 → activate → Converged.
Проверить вызов сервиса на Worker отдельно (общий Gateway может направить Supervisor на Design).

## Что проверено до установки

ZIP CRC, полная распаковка и повторная упаковка, синтаксис JS, вызов C# endpoint из обработчика на
тестовом HTTP-ответе, обновление Total и ошибки ввода. C# со сборками Terrasoft и UI-компоненты
проверяются при установке/запуске в целевом Creatio: до этого runtime-совместимость не подтверждена.
Формат архива и SourceCode-метаданные сверены с исходниками clio, исходная страница взята из
экспорта вашей среды. Не требуется устанавливать clio или .NET SDK на рабочий компьютер.
